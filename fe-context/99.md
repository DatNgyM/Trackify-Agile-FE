## PostgreSQL dev — port, volume, lỗi Prisma P1000

| Nguyên nhân | Gợi ý |
|-------------|--------|
| **Hai Postgres trên cổng 5432 (Windows)** | Kiểm tra: `tasklist \| findstr postgres` — nếu có **postgres.exe** (dịch vụ Windows) **và** Docker `postgres-app` cùng dùng :5432, Prisma có thể nối nhầm → **P1000**. Cách xử lý: tắt dịch vụ PostgreSQL Windows khi dev Docker, **hoặc** dùng infra map **`5434:5432`** và `DATABASE_URL` → `localhost:5434`. |
| **Hai container Docker cùng map 5432** | Chỉ chạy một trong `postgres-app` (infra) hoặc Postgres trong `Trackify-Agile/docker`. |
| **Volume cũ — mật khẩu trong DB ≠ `printenv`** | `POSTGRES_PASSWORD` trong compose chỉ áp dụng lúc **tạo volume lần đầu**. Sửa `.env` infra rồi restart **không** đổi pass đã lưu → chỉnh `DATABASE_URL` backend cho khớp pass thật, hoặc `docker compose down -v` + `up` (mất data local). |
| **Sai `DATABASE_URL`** | Chạy trong thư mục infrastructure: `docker compose exec postgres-app printenv POSTGRES_USER POSTGRES_PASSWORD POSTGRES_DB` — backend `.env` phải cùng user/pass/db. |

Chi tiết comment thêm trong: `trackify-agile-backend/.env.example`, `Trackify-Agile/docker/docker-compose.yml`, `trackify-agile-infrastructure/docker-compose.yml`.
