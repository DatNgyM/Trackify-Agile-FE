# 21 nhánh feature – nói rõ từng nhánh làm gì

Mọi nhánh đều tách từ `develop`, làm xong thì merge về `develop`.

---

## FE – UI & Layout (6 nhánh)


| Nhánh                                  | Làm gì                                                                                            |
| -------------------------------------- | ------------------------------------------------------------------------------------------------- |
| `feature/fe-ui-buttons-inputs`         | Component Button, Input, Label trong `components/ui`                                              |
| `feature/fe-ui-cards-modals`           | Component Card, Modal, Dropdown trong `components/ui`                                             |
| `feature/fe-layout-header-sidebar`     | Header, Sidebar, Nav trong `components/layout`                                                    |
| `feature/fe-design-tokens-tailwind`    | Màu, spacing, theme trong Tailwind (globals, config)                                              |
| `feature/fe-framer-motion-animations`  | Animation dùng chung (page transition, list, modal) với Framer Motion                             |
| `feature/fe-ui-project-task-sub-views` | Giao diện con: form/modal tạo project con, form/modal + list task con trong task detail (UI only) |


> **Ghi chú:** Nhánh `feature/fe-ui-project-task-sub-views` đã gộp thay đổi từ 5 nhánh FE trên (buttons-inputs, cards-modals, layout-header-sidebar, design-tokens-tailwind, framer-motion-animations). Khi tạo nhánh này, merge 5 nhánh đó vào để có đủ UI; nếu đã merge rồi thì sẽ báo "Already up to date".
